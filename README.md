# pans

`pans` is a high-performance server framework built around a multi-Reactor,
multi-threaded, and multi-coroutine architecture.

This project is developed for learning and exploring high-performance server
design, including event-driven I/O, concurrency, coroutine scheduling, and
network programming.

It is suitable for building and experimenting with applications such as:

- Game servers
- HTTP servers
- RPC services
- Other high-concurrency network services
